## 스킬

### financial-statements

AI가 한국 DART와 미국 SEC EDGAR에서 기업 공시, 재무제표와 주석을 찾아 분석합니다. 회사 별칭과 줄임말로도 요청할 수 있습니다.

[스킬 안내](skills/financial-statements/SKILL.md)

## DART 조회 설정

처음 DART를 조회할 때 설정 화면에서 공개 조회나 API 키 등록을 선택할 수 있습니다. 선택한 방식은 다음 실행에도 적용됩니다.

API 키 없이도 공개 DART에서 같은 공시와 주석을 읽을 수 있습니다. 보고서 몇 건이나 우발부채 같은 주석 분석은 공개 조회로 충분합니다. 여러 회사와 기간에 걸쳐 재무 수치를 모을 때는 API로 필요한 항목만 받아 AI 사용량을 줄일 수 있습니다.

API 키를 등록하면 현재 컴퓨터에서 로그인한 계정에 연결된 보안 저장소에 저장됩니다. 공개 조회를 선택한 뒤에도 채팅에서 “DART API 키를 등록하고 싶어”라고 요청하면 등록할 수 있습니다.
